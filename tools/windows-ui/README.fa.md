# رابط دسکتاپ ۳.۶.۶ برای نصب موجود ویندوز

این بسته **نصب‌کنندهٔ کامل برنامه نیست**؛ رابط جدید را با فایل اجرایی فعلی نسخهٔ ۳.۶.x اجرا می‌کند. نسخهٔ بک‌اند در تنظیمات، همان نسخهٔ فایل اجرایی قبلی باقی می‌ماند. اطلاعات و فایل‌های نصب‌شده جایگزین نمی‌شوند.

۱. از اطلاعات فروشگاه بکاپ بگیرید و برنامه را با دکمهٔ خروج خودش کاملاً ببندید.
۲. کل ZIP را در یک پوشهٔ دائمی استخراج کنید، نه داخل ZIP و نه داخل پوشهٔ نصب قبلی.
۳. `START-WINDOWS-UI.bat` را اجرا کنید. اگر محل نصب استاندارد نیست، فایل `SupermarketSystem.exe` نصب‌شده را روی BAT بکشید.
۴. از این پس برای رابط جدید همین BAT را اجرا کنید. اجرای میانبر قبلی، رابط داخلی قبلی را باز می‌کند؛ بنابراین برگشت به نسخهٔ قبلی ساده است.

BAT فقط متغیر `FRONTEND_DIR` را برای فرایندِ برنامه تنظیم می‌کند؛ این قابلیت از قبل در بک‌اند موجود است. برنامهٔ دیگری را نمی‌بندد، دیتابیس را جابه‌جا نمی‌کند و چیزی را از اینترنت دانلود نمی‌کند. اگر برنامه هنوز اجرا باشد، خطا می‌دهد تا خودتان آن را ببندید.

اگر پس از اجرا رابط قدیمی دیده شد، ابتدا بسته بودن کامل فرایند قبلی را بررسی کنید و صفحه را با Ctrl+F5 تازه‌سازی کنید. برای نصب‌هایی غیر از مسیر رسمی PyInstaller یا بک‌اند قدیمی‌تر از ۳.۶.x، سازگاری تضمین نشده است.

آزمون رابط در Chromium لینوکس، روی دادهٔ آزمایشی و API واقعی انجام شده است. **اجرای خود BAT روی Windows و نصب‌ساز Setup.exe جدید در این محیط آزمایش/ساخته نشده‌اند.** این بسته جایگزین ادعای ساخت Setup.exe نیست.
