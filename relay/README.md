# رلهٔ آنلاین «سوپری من» (v2.3)

با این سرویس کوچک، گوشی‌های فروشگاه از **هر جایی** (اینترنت گوشی، شهر دیگر) به رایانهٔ فروشگاه وصل می‌شوند —
بدون IP ثابت، بدون پورت‌فورواردینگ، بدون VPN. رایانه خودش به رله وصل می‌شود (اتصال خروجی)، پس هیچ تنظیمی روی مودم لازم نیست.

```
گوشی ──HTTPS──▶ رله ◀──HTTPS (long-poll)── رایانهٔ فروشگاه
```

- رله **هیچ داده‌ای ذخیره نمی‌کند**؛ فقط درخواست/پاسخ را چند ثانیه در حافظه نگه می‌دارد.
- هر فروشگاه یک «نام» و یک «کلید» دارد (در تنظیمات → همگام‌سازی آنلاین رایانه ساخته می‌شود و داخل QR جفت‌سازی می‌رود).
- توکن ورود کاربر داخل درخواست است؛ رله رمز عبور نمی‌بیند. برای امنیت کامل حتماً HTTPS بگذارید.

## سه روش اتصال آنلاین (از رایگان تا میزبانی‌شده)

| روش | هزینه | نیاز | چه چیزی می‌دهد |
|---|---|---|---|
| **۱. شبکهٔ محلی (Wi-Fi فروشگاه)** | رایگان | هیچ | سریع‌ترین؛ با تغییر IP خودکار پیدا می‌شود (بیکن UDP + پورت ثابت ۸۷۶۵) |
| **۲. Google Drive (پوشهٔ اختصاصی برنامه)** | رایگان | حساب گوگل | همگام‌سازی کالا/موجودی/مشتری/فاکتور با تأخیر ۱ تا ۵ دقیقه؛ گوشی‌ها حتی بدون رایانه هم با هم همگام می‌شوند |
| **۳. رلهٔ آنلاین (همین پوشه)** | یک هاست کوچک (ماهی چند ده هزار تومان یا پلن رایگان PaaS) | نصب این سرویس روی یک هاست/سرور | **همهٔ امکانات برنامه، آنی، از هر جا** — دقیقاً مثل بودن روی Wi-Fi فروشگاه |

روش ۱ همیشه فعال است؛ ۲ و ۳ اختیاری‌اند و برنامه به‌صورت خودکار بهترین مسیر در دسترس را انتخاب می‌کند (LAN → رله → Drive).

## نصب رله (۵ دقیقه)

### الف) روی هر سرور لینوکس / VPS (ایرانی یا خارجی)
```bash
git clone <این مخزن> && cd relay
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn server:app --host 0.0.0.0 --port 8080
```
جلوی آن یک Nginx/Caddy با HTTPS بگذارید (Caddy خودش گواهی می‌گیرد):
```
relay.example.ir {
    reverse_proxy 127.0.0.1:8080
}
```

### ب) با Docker
```bash
docker build -t supery-relay relay/
docker run -d --restart=always -p 8080:8080 supery-relay
```

### ج) روی PaaS ایرانی (پلن رایگان/ارزان: لیارا، پارس‌پک، فندق، …)
یک برنامهٔ «Docker» یا «Python» بسازید، پوشهٔ `relay/` را دیپلوی کنید؛ پورت را از متغیر `PORT` می‌خواند. آدرس HTTPS که می‌دهند همان «آدرس رله» است.

## تنظیم در برنامه
1. رایانه: **تنظیمات → همگام‌سازی آنلاین → رلهٔ آنلاین**: آدرس رله (مثل `https://relay.example.ir`) را وارد و «تولید کلید» و «تست» را بزنید. وضعیت باید «رایانه به رله متصل است» شود.
2. گوشی: کافی است یک‌بار با QR/کد ۶ رقمی جفت شود (آدرس و کلید رله داخل QR است). گوشی‌های قبلاً جفت‌شده با اولین اتصال LAN آن را می‌گیرند.
3. از این پس گوشی هر جا باشد: اول Wi-Fi فروشگاه را امتحان می‌کند، اگر نبود از رله می‌رود، اگر رله هم نبود از Drive.
