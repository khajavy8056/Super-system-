# لایسنس و راه‌اندازی اولیه (v1.5.0)

## سرور لایسنس
Cloudflare Worker مالک: `https://soft-hat-4eba.khajavi8056.workers.dev/`

```
GET ?api_action=validate&key={KEY}&hwid={HWID}
→ {"status":"SUCCESS","type":"FULL","owner":"Demo","expires":"2026-09-30"}
→ {"status":"INVALID","message":"لایسنس یافت نشد"}
→ {"status":"MAX_DEVICES_REACHED","message":"سقف تعداد دستگاه مجاز تکمیل شده است"}
```
هر `status` غیر از `SUCCESS` رد محسوب می‌شود و `message` سرور عیناً به کاربر نشان داده می‌شود (`EXPIRED`, `DISABLED`, … نیز پشتیبانی می‌شوند).

## شناسهٔ دستگاه (HWID)
`SHA-256("supermarket|" + MachineGuid)` (ویندوز: `HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid`؛ لینوکس: `/etc/machine-id`؛ در نبود آن‌ها MAC) → ۱۶ کاراکتر اول به شکل `XXXX-XXXX-XXXX-XXXX`. در همهٔ صفحات لایسنس نمایش داده می‌شود.

## چرخهٔ اعتبارسنجی
| رویداد | رفتار |
|---|---|
| فعال‌سازی (ویزارد / تنظیمات ← لایسنس) | تماس آنلاین؛ در صورت SUCCESS، کلید (secret)، نوع، مالک، انقضا، زمان بررسی و HWID در `system_settings` (`license.*`) ذخیره می‌شود |
| هر درخواست API | فقط از **کش** خوانده می‌شود (بدون شبکه). اگر مجاز نباشد → `402 {"code":"LICENSE_REQUIRED"}` |
| هر ۲۴ ساعت | thread `license-worker` (هر ۱ ساعت بیدار می‌شود) کلید ذخیره‌شده را دوباره آنلاین بررسی می‌کند |
| هر ورود (Login) | صفحهٔ لودینگ `POST /api/setup/license/recheck` را صدا می‌زند (بررسی اجباری) |
| رد قطعی سرور | وضعیت `REVOKED` → برنامه قفل و صفحهٔ لایسنس نشان داده می‌شود |
| خطای شبکه | وضعیت قبلی حفظ می‌شود؛ تا **۷ روز** بدون تأیید آنلاین کار می‌کند، سپس قفل با پیام فارسی |
| انقضا | با رسیدن `expires` قفل می‌شود؛ از ۱۴ روز قبل، هشدار شمارش معکوس در نوتیفیکیشن پایین صفحه |

مسیرهای آزاد از گیت: `/health`, `/api/setup/*`, `/media`, `/icons`, `/docs`.
متغیر محیطی `SUPERMARKET_LICENSE_GATE=0` فقط برای آزمون‌های خودکار؛ `SUPERMARKET_LICENSE_SERVER` برای stub محلی اسموک UI (`scripts/uitest/license_stub.py`).

## API
| متد | مسیر | احراز هویت | شرح |
|---|---|---|---|
| GET | `/api/setup/status` | — | `setup_done`, `first_loading_done`, `license{…}`, `loading_seconds` (۲۷۰۰ بار اول / ۱۲۰ بعدی) |
| GET | `/api/setup/license` | — | وضعیت لایسنس (بدون کلید کامل) |
| POST | `/api/setup/license/activate` `{key}` | — | فعال‌سازی آنلاین؛ 422 با `code` سرور، 503 هنگام قطعی شبکه |
| POST | `/api/setup/license/recheck` | کاربر | بررسی اجباری آنلاین |
| DELETE | `/api/setup/license` | `settings.manage` | حذف لایسنس (تغییر کلید) |
| POST | `/api/setup/complete` | — (فقط تا پیش از اتمام راه‌اندازی؛ نیازمند لایسنس فعال) | نام/اطلاعات فروشگاه، واحد پول، تم، عرض کاغذ، بانک اولیهٔ کالا، نام کاربری/رمز مدیر |
| POST | `/api/setup/logo` | — (همان قاعده) | لوگو |
| POST | `/api/setup/loading-done` | کاربر | پایان لودینگ ۴۵ دقیقه‌ای بار اول |
| GET | `/api/setup/alerts` | کاربر | هشدارهای پایین صفحه: بچ‌های نزدیک انقضا (ساعت/روز مانده) + شمارش معکوس لایسنس |

## ویزارد راه‌اندازی (بار اول)
۱۰ مرحله: خوش‌آمد → **لایسنس** (غیرقابل رد) → نام فروشگاه → لوگو → اطلاعات تماس → واحد پول → پوسته و چاپگر → بانک اولیهٔ کالا (۱۹۰ کالا با موجودی صفر، اختیاری) → **حساب مدیر** (غیرقابل رد؛ جایگزین admin/admin123) → پایان. سایر مراحل «رد کردن» دارند و بعداً از تنظیمات قابل تکمیل‌اند.

## صفحهٔ لودینگ
- بار اول پس از ویزارد: «در حال نصب و پیکربندی» ~**۴۵ دقیقه** با حلقهٔ پیشرفت، ۱۳ فاز و لاگ زنده؛ در همین حین تم و تنظیمات واقعاً اعمال می‌شوند.
- هر ورود بعدی: ~**۲ دقیقه** («بررسی لایسنس، بارگذاری تنظیمات، همگام‌سازی…») همراه با بررسی آنلاین لایسنس.
- کلید تست: `?fastload=<ثانیه>` یا `sessionStorage.sm.loading.fast` (فقط برای اسموک/اسکرین‌شات).
