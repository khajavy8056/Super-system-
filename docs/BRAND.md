# نشان رسا سیستم — منبع، خروجی‌ها و قاعده‌ها

## ۱) منبع واحد

فایل `docs/brand/logo-master.png` (۱۲۵۴×۱۲۵۴، پس‌زمینهٔ سفید) **تنها منبع** لوگو است. هر دارایی دیگری از همین فایل ساخته می‌شود:

```
python scripts/make_logo.py          # ساخت/بازسازی همهٔ خروجی‌ها
python scripts/make_logo.py --check  # کنترل هم‌خوانی (CI)
```

هیچ فایلی را دستی ویرایش نکنید؛ اگر لوگو عوض شد، فقط `logo-master.png` را جایگزین کنید و اسکریپت را اجرا کنید.

## ۲) خروجی‌ها

| مسیر | کاربرد |
|---|---|
| `frontend/icons/logo.svg` | نشان برنامه در پنل، ورود، «درباره» |
| `frontend/icons/icon-192.png` / `icon-512.png` | PWA و manifest |
| `frontend/icons/icon-maskable-512.png` | آیکون ماسک‌پذیر اندروید (منطقهٔ امن) |
| `installer/windows/icon.ico` | آیکون برنامه و نصب‌کنندهٔ ویندوز (۷ اندازه) |
| `mobile-android/.../mipmap-*/ic_launcher.png` | آیکون لانچر اندروید (۵ چگالی) |
| `mobile-android/.../drawable/rasa_logo.png` | لوگوی رنگی داخل برنامه و `setLargeIcon` اعلان |
| `mobile-android/.../drawable-*/ic_stat_rasa.png` | آیکون نوار وضعیت اعلان‌ها (۲۴dp، آلفا-محور) |
| `docs/brand/*` | لوکوپ‌های بازاریابی/چاپ (فارسی، لاتین، زمینهٔ تیره) |

## ۳) قاعده‌های فنی

* **آیکون نوار وضعیت اندروید فقط با کانال آلفا رسم می‌شود.** اگر یک PNG رنگی (لاuncher) به `setSmallIcon` داده شود، اندروید آن را یک لکهٔ سفید نشان می‌دهد؛ اگر آیکون سیستمی مثل `android.R.drawable.ic_dialog_info` داده شود، کاربر «!» می‌بیند — همان شکایتی که در نسخهٔ ۱٫۰٫۵۲۵ وجود داشت و در ۱٫۰٫۵۲۶ رفع شد.
* برای اعلان همیشه جفت استفاده کنید: `setSmallIcon(R.drawable.ic_stat_rasa)` + `setLargeIcon(rasa_logo)`.
* رنگ برند سبز `#10B981` و آبی `#2563EB` است؛ آیکون اعلان تک‌رنگ سفید می‌ماند تا در هر پوستهٔ نوار وضعیت خوانا باشد.
* نشان نباید کشیده شود: نسبت تصویر اصلی حفظ می‌شود و در کاشی گرد با حاشیهٔ ۱۲–۱۳٪ قرار می‌گیرد.

## ۴) نگهبان‌ها

`backend/tests/test_v526_brand_and_notifications.py` این‌ها را تضمین می‌کند: وجود لوگوی اصلی، بازتولیدپذیری همهٔ خروجی‌ها، یکسان بودن نشان پنل/اندروید/ویندوز، آلفا-محور و تک‌رنگ بودن آیکون نوار وضعیت، و اینکه هیچ آیکون سیستمی جایگزین نشان برنامه نشود.

`backend/tests/test_v100_theme_contract.py` هم وجود و غیرخالی بودن دارایی‌های برند و اندازهٔ آیکون‌های لانچر را بررسی می‌کند.
