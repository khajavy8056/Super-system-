# Design System — سامانه سوپرمارکت

مستند رسمی سیستم طراحی (§47). هر صفحه‌ای که ساخته می‌شود **باید** از این توکن‌ها و کامپوننت‌ها استفاده کند — استایل محلی/دستی ممنوع.

## ۱. توکن‌ها (`styles.css` / `mobile/styles.css` — یکسان)

| توکن | مقدار | کاربرد |
|---|---|---|
| `--bg` | `#0f1420` | پس‌زمینه اصلی |
| `--bg2` | `#171e2e` | نوارها/ورودی‌ها |
| `--card` | `#1c2437` | کارت‌ها و پنل‌ها |
| `--border` | `#2a3550` | خطوط جداکننده |
| `--text` | `#e7ecf5` | متن اصلی |
| `--muted` | `#8a94ad` | متن ثانویه |
| `--primary` | `#3b82f6` | اکشن اصلی |
| `--green` | `#22c55e` | موفقیت/پرداخت/سود |
| `--red` | `#ef4444` | خطا/ابطال |
| `--amber` | `#f59e0b` | هشدار (کم‌موجودی/انقضای نزدیک) |

**چرا Dark؟** خوانایی طولانی‌مدت در نور محیط صندوق/انبار، کاهش خیرگی روی مانیتور ارزان‌قیمت صندوق، و یکدستی با POS. حالت Light در نقشه راه است (`if required`).

## ۲. تایپوگرافی
- خانواده: `Segoe UI, Tahoma, Vazirmatn` (فارسی RTL).
- مقیاس: ۱۱ (muted) · ۱۲-۱۴ (بدنه) · ۱۵-۱۶ (دکمه/ورودی موبایل) · ۱۹-۲۲ (عناوین/اعداد بزرگ).
- اعداد پولی/تعداد: `font-variant-numeric: tabular-nums` (ستون‌ها لرزش ندارند).
- بارکدها: `direction: ltr`.

## ۳. فاصله‌گذاری و شکل
- مقیاس فاصله: ۴/۸/۱۰/۱۴/۱۶px (شبکه ۲px).
- شعاع گوشه: ۸ (ورودی) · ۱۰-۱۲ (دکمه/کارت) · ۹۹۹ (badge).

## ۴. کامپوننت‌ها

| کامپوننت | کلاس(ها) | قاعده |
|---|---|---|
| دکمه | `.btn` + `-primary/-danger/-green/-ghost/-sm` | متن همیشه فهرست‌وار؛ دکمه اصلی هر صفحه حداکثر یکی |
| دکمه‌های POS | `.pos-btn` + `-pay/-danger` | حداقل ۴۸px ارتفاع (لمس) |
| ورودی | `input/select` سراسری | پس‌زمینه `--bg2`، فوکوس = outline Primary |
| کارت | `.card` | واحد پایه چیدمان؛ بدون سایه، فقط border |
| جدول | `table` + `thead th` | راست‌چین؛ ستون اعداد tabular-nums |
| Badge | `.badge` + `-green/-blue/-amber/-red/-gray` | وضعیت‌ها: سبز=سالم/موفق، آبی=اطلاع، کهربایی=نیازمند توجه، قرمز=خطا/ابطال |
| Toast | `.toast` + `.ok/.err` | حداکثر ۳ ثانیه؛ خطاها هرگز با toast موفق جا زده نمی‌شوند |
| مودال | `#modal` + `openModal/closeModal` | کلیک بیرون = بستن؛ Escape = بستن |
| نوار پیشرفت | `.progress` | انبارگردانی موبایل/دسکتاپ |
| رسید | `.receipt` | مونواسپیس، پس‌زمینه روشن (چاپ‌مانند)، LTR |

## ۵. قواعد رفتاری UI
1. **RTL و فارسی** برای همه چیز؛ اعداد با `toLocaleString("fa-IR"/"en-US")` بسته به زمینه.
2. **نقش‌محور (§5):** منو فقط آیتم‌های مجاز نقش را نشان می‌دهد (`/auth/me → permissions`)؛ عناصر مالی (سود/بهای خرید) بدون `pricing.view_cost` رندر نمی‌شوند.
3. **Error-Tolerant:** همه درخواست‌های شبکه در try/catch؛ پیام کاربرپسند از `detail.message` سرور (Error-ID برای پشتیبانی).
4. **Keyboard-first در POS** (Enter/F2/F4/F8/Del/Esc) و **Touch-first در موبایل** (دکمه ≥۴۸px، بدون hover-inkar).
5. **Responsive:** شبکه `grid-2/grid-4` با `auto-fill/minmax`؛ POS در `<900px` تک‌ستونه می‌شود.
6. امنیت: هر مقدار کاربر قبل از درج در DOM از `esc()` رد می‌شود (XSS).
